# Studysmarter Pal

Create the first version of a web app called StudyPilot AI, a smart study companion for college students.

Design requirements:

Clean, modern, premium-looking interface.

White background with soft lavender and blue accents.

No black or dark background.

Responsive on laptop and mobile.

Left sidebar navigation with a neat dashboard.

Use readable fonts, rounded cards, simple icons, and good spacing.

Create these pages:

Dashboard — greeting, today's study plan, upcoming deadlines, progress cards, and quick actions.

My Subjects — subject and module list.

AI Notes — syllabus input, topic input, and a Generate Notes button.

Daily Quiz — topic selection, quiz area, and score display.

Study Planner — tasks, deadlines, priorities, and estimated study time.

Progress — quiz scores, completed tasks, and weak topics.

Settings — reminder preferences.

For now, build the frontend layout with realistic sample data clearly marked as demo data. Add working navigation and basic interactions where possible. Do not pretend AI generation, PDF downloads, database saving, or notifications work until they are actually implemented. Keep the code organized so we can connect a backend and AI securely later.

Start with the dashboard and shared navigation, then create the other pages. Do not add unnecessary features.
